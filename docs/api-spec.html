아지트 API 명세

데스크톱 앱(Go · Wails)의 internal/client가 부르는 서버 API 전부. 행을 누르면 요청·응답·에러·구현 메모가 옆에 열려요. 상태 칸을 누르면 구현 전 → 진행 중 → 완료로 바뀌고, 이 브라우저에 저장돼요.

📌 기준
프로젝트 개요(2026-10-07) · 프론트 화면 53개 · 프로토콜 버전 1
🌐 기본 주소
https://{서버}/v1 · 개발 http://127.0.0.1:8080/v1
🔑 인증
Authorization: Bearer {세션 토큰} (불투명 토큰, JWT 아님)
📦 형식
JSON · 필드 이름 snake_case · 시간은 RFC 3339 UTC 문자열
⚡ 실시간
WebSocket GET /v1/ws — 서버 → 앱 한 방향 알림. 보내기는 전부 HTTP
